# Manual administrativo

Accede a `/admin/login` con el administrador único configurado en `.env`. No existe registro de clientes, usuarios adicionales, roles ni permisos.

Desde el panel se gestionan catálogo, taxonomías, contenido, mensajes, multimedia, importaciones, exportaciones, respaldos, calidad y SEO. Antes de importar o eliminar datos, generar un respaldo. Publicar únicamente información confirmada y sin precios o disponibilidad inventados.
