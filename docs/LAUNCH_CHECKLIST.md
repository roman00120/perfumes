# Checklist de lanzamiento

- [ ] PHP 8.2+ y extensiones requeridas.
- [ ] Base creada, credenciales privadas y migraciones ejecutadas.
- [ ] `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL` HTTPS real.
- [ ] Hash administrativo y pepper configurados.
- [ ] Backup verificado.
- [ ] Smoke test y health readiness aprobados.
- [ ] HTTPS y permisos validados.
- [ ] `SEARCH_ENGINE_INDEXING=true` sólo después de confirmar dominio.
