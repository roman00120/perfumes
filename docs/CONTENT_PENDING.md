# Contenido pendiente de confirmar

- Dominio público y URL definitiva.
- Horarios reales de atención.
- Correo institucional y SMTP.
- Redes sociales oficiales.
- Promociones, testimonios, precios y disponibilidad reales.
- Textos legales definitivos.

No se deben inventar ni publicar estos datos hasta recibir confirmación.
